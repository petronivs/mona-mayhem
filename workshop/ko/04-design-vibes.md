# 파트 4: 디자인 우선 테마 구성

---

이 파트에서는 Copilot의 계획 및 구현 흐름을 사용해 전체 테마를 설계하고 적용합니다. 먼저 시각적 방향을 정하고 결과를 반복해서 다듬은 뒤 Copilot이 CSS 구현을 맡는, 디자인 우선 개발 방식입니다.

## 작업 1: 레트로 테마 계획

<!-- track:vscode:start -->
GitHub Copilot Chat에서 **Plan** 모드로 전환합니다.
<!-- track:vscode:end -->

<!-- track:cli:start -->
GitHub Copilot CLI에서 `/plan`을 사용하거나 plan mode가 활성화될 때까지 **Shift+Tab**을 누릅니다.
<!-- track:cli:end -->

다음 프롬프트를 입력합니다.

> 이 페이지를 완전한 레트로 아케이드 경험으로 바꾸고 싶습니다. 배경에 CRT 스캔라인(scanline) 효과를 적용하고, 네온 간판처럼 맥박을 내며 빛나는 제목을 만들고, 그라데이션 색상이 바뀌는 애니메이션 VS 배지를 추가하고, 사용자 결과 카드에 빛이 지나가는 오버레이 효과를 적용하고, 입력란이 떠오르듯 나타나게 하고, 로딩 텍스트가 초록색과 보라색 사이에서 바뀌게 하고, 기여도 사각형에 마우스를 올리면 빛나게 해 주세요. 배경은 어두운 색(`#0a0a1a`), 강조 색상은 초록색(`#5fed83`)과 보라색(`#8a2be2`)으로 유지합니다. Google Fonts의 레트로 게임 글꼴인 Press Start 2P를 사용하는 어두운 테마를 적용합니다.

Copilot은 모든 시각 효과를 포함한 상세한 구현 계획을 생성합니다. **바로 수락하지 마십시오.** 계획을 검토하고 반복해서 다듬습니다.

- 애니메이션 타이밍 조정을 제안합니다(예: *"네온 맥박이 더 천천히, 약 3초 간격으로 움직이게 해 주세요."*).
- 특정 효과에 관해 질문합니다(예: *"카드에 빛이 지나가는 효과는 어떻게 구현하나요?"*).
- 적절하지 않다고 느껴지는 접근 방식은 변경을 요청합니다.

## 작업 2: 테마 구현

계획이 만족스러우면 Copilot에 구현을 요청합니다.

> 방금 설계한 레트로 아케이드 테마 계획을 구현합니다.

Copilot은 스타일시트 전반에 여러 CSS 애니메이션, 의사 요소, 전환 효과를 추가합니다. 예를 들면 다음과 같습니다.

- 스캔라인, 네온 맥박, 빛이 지나가는 효과, 떠오르는 효과를 위한 `@keyframes`
- 오버레이 효과를 위한 의사 요소(`::before`, `::after`)
- 테마 색상을 위한 CSS 사용자 지정 속성
- 인터랙티브 요소를 위한 전환 및 마우스 오버 상태

<!-- track:cli:start -->
변경 사항을 적용하기 전에 `/diff`로 스타일 변경 내용을 검토합니다.
<!-- track:cli:end -->

## 작업 3: 시각 효과 다듬기

> **⚠️ 변경 사항이 보이지 않나요?** 새 테마나 애니메이션이 표시되지 않으면 개발 서버를 중지(`Ctrl+C`)하고 `npm run dev`로 다시 시작한 다음 브라우저에서 강력 새로 고침(`Ctrl+Shift+R`)을 합니다.

브라우저 미리 보기를 열어 두고 디자인을 반복해서 개선합니다. 다음 프롬프트를 사용해 볼 수 있습니다.

> 스캔라인 효과가 너무 강합니다. 불투명도를 0.03으로 줄여 주세요.

> 제목 텍스트에 은은한 전기 깜박임 효과를 추가해 주세요.

> VS 배지가 더 극적으로 맥박을 내게 해 주세요.

이것이 **디자인 우선 개발**입니다. 결과물을 실시간으로 보며 디자인을 반복해서 다듬습니다. "이 정도면 괜찮다"에서 멈추지 말고, 아케이드 게임기에 어울릴 때까지 분위기를 살려 보십시오.

## 작업 4: 지침 업데이트

주요 디자인 결정을 지침에 기록하면 이후 프롬프트에도 같은 방향을 적용할 수 있습니다.

<!-- track:vscode:start -->
Copilot Chat에 다음을 요청합니다.

> copilot-instructions.md에 레트로 아케이드 테마의 색상, 글꼴, 애니메이션 스타일을 설명하는 디자인 가이드를 추가합니다.
<!-- track:vscode:end -->

<!-- track:cli:start -->
Copilot CLI에 다음을 요청합니다.

> 저장소 지침에 레트로 아케이드 테마의 색상, 글꼴, 애니메이션 스타일과 새 UI에도 네온 분위기를 유지한다는 규칙을 간략한 디자인 가이드로 추가합니다.
<!-- track:cli:end -->

페이지가 만족스러우면 업데이트한 지침과 디자인 변경 내용을 커밋합니다.
