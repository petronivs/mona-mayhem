Mona Mayhem 워크숍

레트로 아케이드 스타일의 GitHub 기여 배틀 아레나를 만들며 VS Code용 Copilot 기능인 컨텍스트 엔지니어링(Context Engineering), 계획 모드(Plan Mode), 에이전트 모드(Agent Mode), 디자인 우선 개발, 다중 에이전트 워크플로(multi-agent workflow)를 익힙니다.

Copilot 작업 환경을 선택하십시오.

VS Code 워크숍에서 채팅(Chat), 계획 모드, 에이전트 모드, 백그라운드 에이전트(background agents), 편집기 기반 검토 흐름을 실습합니다.

컨텍스트 엔지니어링

워크스페이스 지침, 백그라운드 에이전트, Ask 모드(Ask mode) 탐색을 활용해 Copilot이 코드베이스를 이해하도록 돕습니다.

📋

계획 모드

코드를 작성하기 전에 아키텍처를 설계하고 계획을 충분히 다듬은 뒤 확신을 가지고 구현합니다.

🤖

에이전트 모드

Copilot이 여러 파일에 걸쳐 기능 전체의 초기 구조를 자율적으로 스캐폴딩(scaffolding)하게 한 뒤, 피드백을 반영해 반복 개선합니다.

🎨

다중 에이전트 워크플로

백그라운드 및 클라우드 에이전트를 활용해 반응형 디자인, 오류 처리 UX, 테마 변형 등을 병렬로 다듬습니다.
